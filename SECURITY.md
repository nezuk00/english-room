# Безопасность MVP

Не добавляйте ключи, токены, транскрипты реальных учеников или базы данных в Git. Используйте .dev.vars и секреты сервера. Репозиторий исключает рабочие базы, логи, локальное состояние инструментов и ID агента владельца.

Для развёртывания с реальными пользователями требуется доверенная аутентификация, приватный агент с signed URL, ограничения расходов и реализованное удаление/экспорт данных. Открытый агент с проверкой Origin не является достаточной защитой квоты.

Об уязвимости сообщайте через личный канал владельцу GitHub-профиля; не публикуйте реальные секреты в issue.
