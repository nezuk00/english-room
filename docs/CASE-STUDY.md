# English Room — проектный кейс

## Задача

Собрать личный MVP, в котором преподаватель ведёт короткий урок английского, даёт задания и сохраняет результат. Основной проверяемый сценарий — заказ в кафе на уровне A2.

## Реализация

Проект объединяет интерфейс урока, серверное хранение и голосового агента. Агент получает текущий этап и историю, а инструменты связывают его реплики с действиями в приложении. Оценка ответов вынесена на сервер: модель не выбирает себе балл и не получает правильные варианты в обычном контексте.

В пробном уроке сначала есть поддержка и образец фразы, затем второй короткий заказ с другим напитком. Это позволяет отделить повторение за преподавателем от попытки ответить самостоятельно. Произношение по текстовой расшифровке не оценивается.

## Технические решения

- React и TypeScript для комнаты урока и её состояний.
- ElevenLabs SDK для разговоров, прерываний и транскрипта; инструкции и два клиентских инструмента — для ведения урока.
- Cloudflare D1 / SQLite для данных, серверные проверки владельца и доступа.
- Стабильные токены запросов и сохранение сообщений для повторов, обрывов и продолжения занятия.
- Сценарные проверки API: доступ, порядок этапов, повтор запросов, проверка ответов и завершение урока.

## Статус

Личный MVP, созданный с использованием агентных инструментов разработки. Публичная версия исходников основана на восстановленном A2 café-пилоте; поздние детские эксперименты в неё не входят. Это не коммерческое внедрение и не подтверждение педагогической эффективности. Ограничения и запуск описаны в README.
