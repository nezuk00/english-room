# Разработка

Сначала воспроизведите изменение локально по SETUP.md. Для изменений урока сохраняйте четыре этапа, русскую навигацию и английский диалог. Проверяйте владельца сессии и повторные запросы при изменении API. Не редактируйте применённые миграции; добавляйте новые.

Перед предложением изменения выполните typecheck, сборку и подходящие сценарии tests/. Изменение teacherPrompt в файле требует отдельного обновления вашего агента ElevenLabs.
